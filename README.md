## ✨ 项目亮点

- **无 ROS 依赖**：单二进制部署，告别中间件开销
- **极致低延迟**：亚微秒级调度，为实时性而生
- **高度可扩展**：模块化流水线，灵活定制各处理阶段
- **精准调试支持**：正在开发完整的精准调试支持：完整的基准测试套件，支持全链路性能与精度分析
    - [x] **全链路追踪**：精确测量每个处理阶段的耗时，定位性能瓶颈
    - [x] **精度评估**：
        - [x] 自动计算检测准确率
        - [ ] 追踪稳定性
    - [x] **回归测试**：确保算法更新不引入性能回退
- **开箱即用**：完整的自瞄解决方案，从检测到击发
- **模拟器友好**：与[daedalus](https://github.com/Blackjack200/bevy_robomaster_simulator)协同，支持离线开发与测试

## 🏗️ 系统架构

Talos 采用多级流水线架构，数据在各阶段间高效流转：

> 📷 采集 → 🔍 检测 → 🎯 追踪 → 📐 解算 → 📡 通信 → 🤖 控制

| 阶段 | 职责             |
|----|----------------|
| 采集 | 相机驱动、帧同步、时间戳对齐 |
| 检测 | 装甲板识别、目标分类     |
| 追踪 | 状态估计、运动预测、目标关联 |
| 解算 | 位姿估计、弹道计算、瞄准决策 |
| 通信 | 下位机交互、控制指令下发   |
